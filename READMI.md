# 🔢 Number Explorer

A simple, interactive web application built with **HTML, CSS, and JavaScript** that allows users to explore different mathematical properties of a number.

This project is part of my JavaScript learning journey, focusing on mathematical operators, built-in JavaScript methods, conditional statements, and DOM manipulation.

## 🚀 Features

Users can enter positive numbers, negative numbers, decimals, or zero to calculate:

- **Even or Odd** — Determines whether an integer is even or odd.
- **Square** — Raises the number to the power of 2.
- **Cube** — Raises the number to the power of 3.
- **Square Root** — Calculates the square root of non-negative numbers.
- **Absolute Value** — Returns the absolute value of a number.
- **Rounded Down** — Rounds down to the nearest integer.
- **Rounded Up** — Rounds up to the nearest integer.
- **Rounded** — Rounds to the nearest integer.

### Input Validation

- Displays an error message when the input is empty.
- Identifies decimal numbers as `Not an integer` for the Even or Odd calculation.
- Displays `Not a real number` when calculating the square root of a negative number.

## 🛠️ Technologies Used

- **HTML5** — Application structure
- **CSS3** — Responsive design and styling
- **JavaScript (ES6+)** — Calculations, validation, and DOM interactions
